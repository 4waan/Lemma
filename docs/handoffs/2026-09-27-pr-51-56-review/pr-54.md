### Findings

1. **Should fix soon (backlog item 42).** Nothing checks at startup that the reputation registry's `getIdentityRegistry()` equals `ERC8004_IDENTITY_REGISTRY`. The ABI has the function (`reputation/abi.ts:136`) but `reputation/index.ts` never calls it. A mismatched pair would post feedback about agent ids from another identity registry, and every evidence file would name the wrong `agentRegistry`. One read at startup, refusing to start on mismatch, closes it.
2. **Follow-up (item 44).** `reputation/config.ts:15` defines a second `SecretKey` while `apps/server/src/config.ts` already has `Secret`, and `chain.ts:170` gives viem the RPC URL as a plain string without the redacting transport from `payments/rpc.ts`. Today no code path logs `error.message`, so nothing leaks; the risk is the next log line someone adds. Unify.
3. **Follow-up (item 40).** `findFeedback` scans fixed `ERC8004_LOG_RANGE` windows (`chain.ts:106`, `:254`) from the first attempt's block on every retry, with no halving on a refused range, no retry cap (`delayAfter` grows to an hour and stays there), and no `ERC8004_FROM_BLOCK` guard for a database restored from a backup.
4. **Follow-up (item 41).** After a key rotation, every queued post is skipped as `FILE_MISMATCH` (`attester.ts:289`), and summaries count only the current attester.
5. **Follow-up (item 39).** `app.ts:148` applies CORS for the dashboard origin only, so other sites cannot read the registration or evidence files.
6. **Follow-up (item 52).** The feed cursor is in memory (`attester.ts:109`); a restart re-reads the feed from the start. Queueing is idempotent and skipped rows stay skipped, so nothing is posted twice and skip codes do not repeat; only `reputation.outcome_invalid` warnings repeat. The backlog's wording ("logs its skip codes again") overstates it.
7. **Nit (item 56).** `parseRegisterArgs` refuses only `0x`-prefixed 64-hex arguments (`register.ts:61`); a bare 64-hex key passes. `setup-roles.ts` and `warranty-admin` already refuse both forms. Unknown options are not echoed, which the backlog also asks for.
8. **Nit.** The evidence route is `/api/v1/evidence/:resolutionId/:target`; the backlog (WP-07) and `docs/arbitrum.md` (#34) write it without `:target`.
